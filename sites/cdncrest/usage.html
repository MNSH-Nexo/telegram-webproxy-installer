Usage guide

Upload once, reference forever. Everything below works from a plain shell.

Upload a build

curl -T dist/app.min.js \
  -H "Authorization: Bearer $TOKEN" \
  https://__DOMAIN__/p/my-lib/1.0.0/app.min.js

Integrity hashes

Every upload gets a sha384 digest, available at the same path with a .sha384 suffix. Paste it into the integrity attribute and keep crossorigin="anonymous".

Cache headers

Immutable files

Cache-Control: public, max-age=31536000, immutable for every versioned path.

Version index

The /p/name/ listing is cached for five minutes so new releases show up quickly.

Limits

Files up to 25 MB, 2,000 files per project. Need more? Contact the team from the About page.
